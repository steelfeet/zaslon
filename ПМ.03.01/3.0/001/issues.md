## ✅ Исправлено в v2.0
- [x] **Загрузка изображений на фон:** Устранен синтаксический баг в JavaScript, из-за которого Data URI не парсился браузером. Теперь фон успешно устанавливается. Обработчик `onchange` сбрасывается для повторных загрузок.
- [x] **Прозрачность UI:** Информационные панели `panel` сделаны полупрозрачными (70% opacity) и дополнены эффектом матового стекла (`backdrop-filter: blur(10px)`). Это позволяет видеть загруженные обои сквозь блоки, сохраняя читаемость текста.
- [x] **Оптимизация фильтров:** Фильтры (ч/б, сепия, инверсия) применяются только к слою `bg-layer` и не искажают элементы интерфейса.
## ✅ Исправлено в v2.1
- [x] **Управление размером элементов UI:** Внедрен `ResizeObserver` и CSS `resize`. Теперь пользователь может вручную изменять ширину и высоту каждого графика, потянув за его угол, что позволяет самостоятельно выравнивать сетку (Grid).
- [x] **Редизайн логотипа:** Унылый черный логотип заменен на яркий анимированный градиент.
- [x] **Баг прозрачности при экспорте PNG:** При скачивании графика (кнопка "Скачать") фон больше не прозрачный — он предварительно заливается белым цветом на виртуальном холсте.
## 🐛 Выявленные баги (Требуют исправления в будущем)
1. **Адаптивность (Mobile):** На устройствах с шириной экрана менее 768px верхняя панель (Top Bar) ломает верстку. Требуется перевести меню в "бургер".
2. **Экспорт в PNG на мобильных:** Кнопка скачивания может не срабатывать во встроенных браузерах Telegram/VK.
