## 1. Содержательная основа

1.1. Какие понятия/термины/процессы проверяет интерактив?

Актуализация (сцена 2, 4):

электромагнитная волна, связь частоты и длины волны: λ = c/f;

энергия кванта E = hf — почему радио не ионизирует, а гамма ионизирует;

несущая, модуляция, полоса АМ-сигнала B = 2F<sub>м</sub>;

глубина модуляции m, перемодуляция.

Новая тема (сцены 5–6):

дифракция: огибание препятствия, если λ соизмерима с ним;

параметр Френеля для ножевого края, потери по ITU-R P.526;

ионосферные слои D, E, F; отражение КВ, поглощение ДВ/СВ днём, прозрачность для УКВ;

радиогоризонт d ≈ 3.57·(√h₁ + √h₂) км.

Применение и ИБ (сцены 7–8):

диапазоны и их применение (ДВ, СВ, КВ, УКВ, СВЧ);

направленная антенна, ППРЧ, экранирование как меры снижения риска перехвата/подавления/утечки;

связь с триадой КЦД.

1.2. Какие вопросы/задания/сюжетные ходы используются?

Сценарий: цель → актуализация (шкала + модуляция) → определения → дифракция → ионосфера → тренажёр диапазонов → ИБ → тест. Ползунки с обратной связью, объясняющей закон. Тренажёр — drag-and-drop карточек в корзины диапазонов. Тест — 7 вопросов на понимание, не на заучивание. Чек-лист конспекта в конце.

1.3. Откуда взято содержание?

Лекция по теме «Принципы радиосвязи. Распространение радиоволн» (ПМ.03.01, тема 3.1.500).

Учебник/пособие по ТЗИ (уточнить выходные данные при финализации).

ITU-R P.526 «Propagation by diffraction» — для модели ножевого края.

Физика: уравнение волны, закон Фарадея, АМ-модуляция, ионосферное распространение (школьный/вузовский курс).

ГОСТ/нормативные документы по защите информации от утечки по техническим каналам (уточнить при финализации).
